## 操作

WASD／方向鍵散步、Shift 快走；拖曳或手機滑動環視，滾輪／雙指調整距離。左下搖桿適用桌面與手機。「回到參道」可離開角落。C 攝影、P 快門、Esc 返回、M 地圖、R 回入口。

地圖含車站商店街／境內／山路，可點目的地快速前往。四辻附近開「茶屋歇腳」選點心或前往茶屋前廊。照片長邊至少 2560px，可隱藏小星星；相簿點照片下載，最多保留最近 6 張於目前瀏覽器。

## 畫質與效能

平滑：原生裝置密度，最高 4× MSAA＋SMAA。精緻：DPR1 螢幕加 1.5× 超取樣，1920×1080 視窗實際繪製 2880×1620。流暢：明確選用的 DPR1、最高 2× MSAA＋FXAA。取樣數依硬體支援，不因低 FPS 自行降低解析度。

優化包括保留頂點索引及 UV／法線接縫、分區地形、逐實例視錐剔除；獨立陰影實例保留鏡頭外投影。SMAA 採 RG8 邊緣遮罩，混合與輸出合併。一般遊玩不保留不用的取樣深度／中間色彩副本，照片需要時配置並在拍完釋放。環境反射以完整 render target 清理。呈現上限 60 FPS，背景分頁明確暫停。

最終 1080p Intel UHD／RTX3050 比較、GPU 每幀時間、私有 RAM 與 GPU 記憶體見 verification/v3/效能報告.md。不能保證任何一般筆電都穩定 60 FPS；也不能把幾何資料減量當成整個瀏覽器 RAM 的減量。此版未加入遠區串流卸載；RAM／GPU 降幅依實測，不保證所有情境 30%～40%。

## 真實程度

核心建築、道路採 OSM 2026-10-25 快照與 GSI 高程；主要山路約 2,343m。建築外觀、雕刻、招牌、茶屋、植栽和城市遠景是照片參考或程式美術重建，附屬建築有共用構件。城市非逐棟京都資料，茶屋非精確測繪店面，攤販非即時營業配置。不是實景掃描或照片級還原，不作導航。官方照片／3DGS 僅作參考，未直接嵌入或散布模型。

## 編輯與驗證

入口 dist/experience.js；執行 node serve.mjs 4186，瀏覽 http://127.0.0.1:4186。dist/ 可作靜態網站。

- node build-offline.mjs：打包單檔，需 esbuild，會使用工作區既有依賴。
- node qa-v3.mjs：車站／茶屋行走、天氣、點心、抗鋸齒、照片與高 DPI 手機。
- node qa-regression.mjs：所有登錄建築四向防穿越、樓門通行、手機觸控、相簿下載／保存等 36 項回歸。
- node qa-routes.mjs：雙列千本鳥居與九段山路；node qa-offline.mjs：離線、照片、減少動態效果與外部請求。
- scripts/prepare-map.py、scripts/prepare-district.mjs：從保留快照重建資料。測試腳本含本機 Chrome／Playwright 路徑，移機需調整；遊玩免依賴。

最新證據見 verification/v3/、ACCEPTANCE.md；僅保留 V2.3 與 V3 的驗收資料。手機為 Chromium 模擬，尚未驗證實體 iOS／Android／Safari。授權、官方參考、GitHub 技能來源見 dist/assets/CREDITS.md。

V3另針對高解析全景加入枝葉深度預通道，先排除被遮住的枝葉再做完整PBR材質計算。四季×四視角×兩畫質共32組對照，實際畫布像素差異皆0；1080p精緻全景樣本的GPU每幀時間由17.3ms降至12.2ms。詳見 verification/v3/depth-pixel-matrix.json 與 depth-prepass.json。

V3.1效能邊界：RTX3050的1080p平滑/精緻六個樣本平均約60FPS；貼圖與遠處細部記憶體降低，但新增內容使總私有RAM仍約620–671MiB，高於本次V3.0樣本，未達整體RAM下降30–40%。詳見 verification/v3/v3.1/效能報告.md。
